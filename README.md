# 🧠 AI Diet Planner

An AI-powered nutrition and calorie planning system built with HTML, CSS, and JavaScript.

This project calculates:

- 🔥 BMR (Basal Metabolic Rate)
- ⚡ TDEE (Total Daily Energy Expenditure)
- 🎯 Goal calories
- 💪 Protein targets
- 🍚 Carb targets
- 🥑 Fat targets

Then dynamically generates:

- 🍽️ Auto meal plans
- 🌍 Country-based food systems
- 🥗 Veg / Non-Veg / Vegan / Eggitarian diets
- 🧮 Calorie-balanced food selections
- ⚠️ Medical safety warnings

# 🧪 Running Locally

Clone repository:

```bash
git clone https://github.com/0xDL01/ai-diet-planner.git
```

Open:

```text
index.html
```

or run:

```bash
python3 -m http.server 8000
```

Then visit:

```text
http://localhost:8000
```
